# Constitution

## Mission

To create a QR scan module, used by volunteers checking tickets at the event desk entry.

## Useability for End Users

- User interface aimed at persons without technical knowledge; when options are needed, a sensible default must be chosen.
- Error messages must be human readable, so that end user knows what to do; if technical support is needed for solving: clear indication of where error occurred.

## Useability for Support

- Easy install using standard methods of chosen tech stack.

## Principles

1. **User-Friendly Interface**
   - The interface must be intuitive and accessible to non-technical users.
   - Default options must be sensible and user-friendly.
   - Error messages must be clear and actionable.

2. **Support-Friendly Installation**
   - Installation must be straightforward using standard methods.

## Governance

### Amendment Procedure

- Any amendment must be documented and approved by the governance team.
- Amendments must be clearly stated with a rationale.

### Versioning Policy

- Versioning must follow semantic versioning rules.
- MAJOR: Backward incompatible governance/principle removals or redefinitions.
- MINOR: New principle/section added or materially expanded guidance.
- PATCH: Clarifications, wording, typo fixes, non-semantic refinements.

### Compliance Review

- All amendments must be reviewed for compliance with the principles.
